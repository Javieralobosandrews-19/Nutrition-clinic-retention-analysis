# Power BI Dashboard

Dashboard desenvolvido em Power BI para análise de retenção, comparecimento, ausências e priorização de pacientes em uma clínica de nutrição.

## Principais indicadores

- Total de consultas
- Taxa de comparecimento
- Taxa de ausência
- Retenção em 30, 60 e 90 dias
- Tempo médio até o primeiro retorno
- Pacientes prioritários por risco de abandono
- Receita registrada
- Valor associado a ausências

## Ferramentas utilizadas

- Power BI
- DAX
- Modelagem relacional
- Python
- SQL

> Os dados utilizados neste projeto são simulados.
